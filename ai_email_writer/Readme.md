# AI Email Writer

## Description

AI Email Writer is a Python-based mini project that uses the Ollama Cloud API to generate professional emails based on user-provided information.

The user provides the purpose, recipient, tone, and important details of the email. The program sends this information to an AI model through the Ollama API and displays the generated email.

## Features

- Generate emails using AI
- Select different email tones
- Provide custom email details
- Uses Ollama Cloud API
- Simple menu-driven interface

#### API Key Setup

This project uses an Ollama API key.
Set the API key as an environment variable.

## Technologies Used

- Python
- Ollama Cloud API
- Requests library
